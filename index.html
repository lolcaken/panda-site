What it does

  1. 01

    Fishing

    Casts on a loop, lands a perfect cast, watches the reel bar and plays the minigame out. Four minigame controllers ship: Lullaby, Maelstrom, Noiseform and Pinions Aria. Timing is jittered so a session doesn't read like a metronome.

  2. 02

    Fish & relic overlay

    A click-through window over the game marks every roaming fish with name, rarity and distance. Rarity filters, tracers, edge markers and per-tier colours. Relics get their own switch and palette.

  3. 03

    Harpoon

    Targets by rarity and range, aims with a sampled controller and throws. Used instead of rod fishing when the water needs clearing.

How it runs

Three processes. If one falls over, the game doesn't notice.

BlackPANDA.exe

The window. Holds settings, writes config, starts and stops the rest.

BlackPandaCore.exe

Attaches to the client read-only, resolves offsets, runs the automation modules.

BlackPandaOverlay.exe

Owns the overlay window. 60 fps, per-pixel alpha, F8 to hide.

The core opens the game with PROCESS_VM_READ and nothing else. No writes, no injection, no DLLs. Input is synthesised the way a keyboard does it.

FAQ

Where should I download it from?

This page. Builds posted anywhere else aren't ours. Compare the SHA-256 above with the file you get.

Does it inject into the game?

No. The core reads memory, the overlay draws in its own window, the macro sends input. Nothing is loaded into the game process.

SmartScreen says unknown publisher.

The build isn't code-signed. Choose More info → Run anyway. The checksum is published so you can confirm the file first.

Will it survive a game update?

Offsets are fetched for the exact client build that's running, so a game update doesn't need a new release. A change to the game's own structure can need a patch — that's what updates are for.
